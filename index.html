    지금 먼저 볼 화물

    위험이 몰린 곳

    ① 비용 공지 읽기

    선사 공지 원문을 HyperCLOVA X가 읽어 비용 규칙(금액·통화·단위·누가 내는지·적용 범위)으로 정리했습니다. 코드가 금액과 근거 문장을 원문과 대조하고, 10/15에 사람이 원문으로 확인한 값과 다른 칸은 막습니다. 도착 지연 예측에 쓰는 공지·뉴스 12건은 아래 '지연 신호'에 따로 있습니다.

    ② 영향받는 화물 찾기

    ③ 판단과 대응 결정

    고른 화물의 추가 비용을 누가 낼지 HyperCLOVA X가 근거와 함께 따지고, 코드가 인용·숫자를 원문과 대조하고 규칙 기준선과 비교합니다. 같은 1,000번의 가상 운항 위에서 대응안마다 도착 범위와 보관료도 비교합니다. 결정은 담당자가 합니다.

    ④ 정산 요약

    담당 화물 전체에 걸린 추가 비용을 '화주에게 청구 가능 / 검토 필요 / 포워더 부담 가능성 / 현지에서 수하인이 냄'으로 나눴습니다.

    ⑤ 선사 확인 요청 메일

    공지만으로는 해석이 갈리는 점을 선사·현지 대리점에 묻는 영문 메일 초안입니다. 이의 제기가 아니라 확인 요청이며, 자료에 없는 숫자는 쓰지 않았습니다.

    ⑥ AI 작업 로그

    단계별로 HyperCLOVA X를 몇 번 불렀고, 토큰과 비용이 얼마였고, 코드 검사를 통과했는지 기록입니다. API 키와 보낸 원문은 넣지 않았습니다.

    참고: 지연 신호 (공지·뉴스)

    도착 시점 예측에 쓰는 신호입니다. 선사 공지와 뉴스를 HyperCLOVA X가 읽고 항만·선사·목적지를 뽑아 정리했습니다. 카드를 누르면 원문과 AI 정리, 원문에서 그대로 옮긴 근거 문장을 나란히 봅니다. 추가 비용 판단에 쓰는 선사 비용 공지 3건은 STEP 1에 있습니다.

    새 공지 넣어 보기 (지연)

    선사 공지나 뉴스 문장을 HyperCLOVA X가 정리하고, 담당 화물 중 해당 화물을 찾는 기능입니다. 실시간 분석 서버가 연결되지 않은 버전에서는 미리 실제로 호출해 둔 분석 결과를 보여 줍니다. 화주 이름, 전화번호, 이메일은 보내기 전에 가립니다.
